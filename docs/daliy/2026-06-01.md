VM 개념은 Pintos와 거의 동일하다. 내부 코드는 20번 강의에서 대부분 설명해주고, 개념을 알면 그렇게 어렵지도 않음.

heap 확장은 `uvmalloc`/`uvmdealloc`을 사용해서 가능하다. 

메모리 구조가 스택이 아래에 있고, 힙이 위에서 계속 올라가는 식인데, 
편의 상 스택 크기가 고정되어있으니 heap이 커질 때 충돌을 걱정하지 않게 이런 식으로 설계한게 아닐까 싶다.

그리고 시스템 콜을 통해서 유저 영역을 읽을 때, 커널 영역에 복사하고 처리후 다시 옮기는 식으로 동작한다.   
(Pintos때는 유효성 검사만 하고 커널에서 유저 영역에 직접 접근하게 구현함.)

실제 리눅스에서도 이처럼 복사가 발생하고, 이 문제 때문에 성능 저하나 I/O blocking 문제가 있는 듯 하다.    
(복사가 발생하지 않는 zero-copy, mmap를 사용하는 식으로 해결한다.)

### 주요 VM 헬퍼 함수 정리

#### 페이지 테이블 탐색/매핑
- `walk`: 3단계 page table을 따라 내려가 특정 VA의 leaf PTE 주소를 찾는다.
- `mappages`: `walk()`로 찾은 leaf PTE에 PA와 permission을 넣어 VA -> PA mapping을 만든다.
- `walkaddr`: user VA가 유효한지 확인하고 PA로 변환한다.

#### 커널 페이지 테이블
- `kvmmake`: kernel page table을 만들고 MMIO, kernel text/data, trampoline, kernel stack을 매핑한다.
- `kvmmap`: kernel page table에 mapping을 추가하는 `mappages()` wrapper.
- `kvminit`: 전역 kernel page table을 만든다.
- `kvminithart`: `satp`에 kernel page table을 넣어 현재 hart에서 paging을 사용하게 한다.

#### 유저 주소 공간 관리
- `uvmcreate`: 빈 user page table을 만든다.
- `uvmalloc`: user address space를 키우기 위해 physical page를 할당하고 mapping을 추가한다.
- `uvmunmap`: user VA 범위의 mapping을 제거하고, 필요하면 physical page도 free한다.
- `uvmdealloc`: user address space를 줄인다.
- `uvmfree`: user address space 전체를 해제한다.
- `freewalk`: page table tree의 page-table page들을 재귀적으로 free한다.
- `uvmcopy`: `fork()` 때 부모 user memory를 자식에게 복사한다.
- `uvmclear`: stack guard page처럼 user 접근을 막아야 하는 page의 `PTE_U`를 지운다.

#### 커널-유저 복사
- `copyin`: user virtual address에서 kernel buffer로 복사한다.
- `copyout`: kernel buffer에서 user virtual address로 복사한다.
- `copyinstr`: user virtual address에서 null-terminated string을 kernel buffer로 복사한다.
