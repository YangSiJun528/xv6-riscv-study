# 11. Memory Layout

AI 정리: [docs/ai/010_xv6_script_11_memory_layout_20260525.md](/docs/ai/010_xv6_script_11_memory_layout_20260525.md)

Pintos와 비슷하게 VA:PA 매핑이 direct(1:1)로 있음.

그리고 high VA에는 `TRAMPOLINE`이나 `KSTACK`를 가지는데,  
이것도 결국 PA에 있으므로, 동일한 PA를 바라보는 VA가 여러개인거임.

User 영역도 마찬가지, KVA, UVA가 각각 존재하는 것.

그리고 Pintos에선 없던 설명인데, xv6에선 mmio로 메모리 매핑되어서 IO를 처리함.  
(설명이 빠진건지 생략한건지, 다른 구현인지는 모름)
