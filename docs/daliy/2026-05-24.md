  - pintos는 싱글코어였음. 근데 코드 상의 큰 차이는 없는듯? (이따 스핀락 챕터에서 추가 설명)

  - 커널 내부에선 malloc 기능이 없고, page 단위로만 할당 가능.
  - pintos랑 다른 부분은 heap이 있다는거?
- 배열 위주 구현
  - 간단하게 구현하기 위해서 linked list를 잘 안쓰는듯
  - 프로세스, CPU, File 등에 최대 크기가 고정된 배열을 사용함 ([param.h](/kernel/param.h) 참고)
